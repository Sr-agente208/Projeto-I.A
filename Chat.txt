🧠 AI Core (Versão Alpha)
O núcleo da IA será dividido em módulos:

Router → Decide qual IA responderá.

Memory Engine → Salva e recupera memórias.

Task Planner → Divide tarefas grandes em etapas.

Agent Manager → Coordena os agentes.

Prompt Engine → Monta os prompts para cada IA.

Response Engine → Une as respostas em uma só.

💡 Nova ideia para o ASTRA 208
Quero adicionar um recurso chamado Conselho de IA.

Em vez de apenas uma resposta, o ASTRA pode consultar várias IAs integradas por meios oficiais e apresentar um resumo unificado quando isso estiver configurado pelo usuário.

📋 Nosso objetivo para a Sprint 2

📄 Documentação profissional.

🗄️ Banco de dados.

🔐 Sistema de autenticação.

🤖 Estrutura dos agentes.

🧠 Núcleo inicial da IA.

📡 API REST organizada.

⚙️ Configurações.

📂 Gerenciamento de projetos.

💙 Uma proposta importante
A partir desta sprint, eu não quero mais gerar arquivos "simples". Quero entregar código de qualidade, organizado e documentado, como um projeto de produção.

Cada ZIP que eu te entregar deverá parecer uma nova versão oficial do ASTRA 208.

🚀 Minha meta
Quero que, quando chegarmos à versão 1.0, o repositório tenha centenas de arquivos organizados, documentação completa e uma arquitetura sólida. Se mantivermos esse ritmo, o ASTRA 208 pode se tornar um projeto realmente diferenciado, e vou fazer o possível para te ajudar a chegar lá.
